Reminders 1.0.0 test build for Android 8 and later.

Includes five recurrence modes, local SQLite storage, English/Arabic, RTL, light/dark themes, calendar, live birthday age, notification actions and JSON backup/restore.

This APK uses development signing. Production signing requires the owner's keystore configuration. The real-phone alarm checklist (screen off, reboot, time-zone changes, killed-app actions and vendor battery restrictions) remains to be completed before production distribution.

Validation: Flutter analysis, recurrence/age tests, database and backup tests, fake notification scheduler tests, editor/list/RTL tests and screen regressions. The recurrence core has 100% line coverage.
